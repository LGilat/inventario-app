# 📦 Inventario App

Sistema de gestión de inventario completo desarrollado con **Node.js**, **Express** y **JavaScript**.

## ✨ Funcionalidades

- Gestión completa de productos (CRUD)
- Control de stock y alertas de bajo inventario
- Registro de entradas y salidas de mercancía
- Búsqueda y filtrado de productos
- Interfaz web responsive
- API RESTful con Express

## 🛠️ Tecnologías utilizadas

- **Backend**: Node.js + Express
- **Base de datos**: (MongoDB / MySQL / Prisma sqlite)
- **Frontend**: HTML, CSS y React
- **Control de versiones**: Git

## 🚀 Objetivo

Facilitar el control y seguimiento de inventario de forma sencilla y eficiente para pequeños negocios o como proyecto de aprendizaje.
